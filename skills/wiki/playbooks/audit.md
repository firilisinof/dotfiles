# Audit

Start with the named project, question, or skill. Compare its current instructions with the implementation, an actual artifact, or the user's dated decision. Report the note, the evidence and the smallest correction that would prevent the next reader from going wrong. Distinguish a dated historical fact from an instruction still presented as current.

When a repeated mistake is mechanical, identify the check that could catch it. When only a skill's procedure was wrong, propose a change in that skill's source. Preserve rare personal facts and recovery experience. An audit request returns findings. Apply changes when requested.

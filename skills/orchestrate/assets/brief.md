# Worker brief

**Context**

Give the worker the relevant paths, inputs and decisions. Assume it has no earlier conversation.

**Task**

Specify one outcome and what counts as complete.

**Rules**

State file ownership, allowed operations, and any constraints. You are a subagent. Do not edit the wiki.

**Output**

Specify the format, evidence and checks to return. For example, ask for a table of source paths and observed values, with missing values marked explicitly.

# Orchestrate

Use this role when the user asks for delegation. The coordinator owns the plan, integration, verification and user communication. Only the coordinator writes to the private wiki.

1. Identify the deliverable, acceptance criteria and dependencies. Resolve consequential ambiguity. Write a short plan before assigning work. Delegate substantive pieces in small, independently verifiable units. Start independent jobs together and wait for prerequisites before assigning dependent ones.
2. Send each worker a self-contained [brief](assets/brief.md). Include only the context and inputs it needs. Scope edits to distinct files when workers share a checkout. Use the current harness's supported delegation tool and fields. A small, fast worker is appropriate for a bounded job when model selection is available and permitted.
3. Inspect each result against its brief. Check evidence, inspect actual changes and run the integration check yourself. If a result misses its target, clarify and reassign the bounded job. After three failed attempts change the approach. If delegation is unavailable, tell the user how this affects the requested work.
4. Combine the verified results into one answer. State what remains incomplete or uncertain. Clean up temporary fixtures, sessions and working directories made for the task.

# Draft

Record the outcome, scope, decisions still needed and the evidence that will establish completion. Use [the plan template](../assets/plan.md) when creating a file. Keep an independent plan at `plans/<slug>.md` or a project plan at `plans/<project>/<slug>.md`. When a plan grows, turn it into a directory with an overview and linked phases. Anchor every phase in an observable result.

Add a relative Markdown link in the appropriate section of `plans/index.md`, and from the project home when applicable. The plan itself owns its status. Keep an unaccepted plan proposed. The user decides when work starts. Track actionable commitments in Things only with consent.

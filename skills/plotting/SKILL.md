# Plotting

Start with the comparison the reader needs to make. Read the project's figure rules and inspect an accepted figure and its generating script when available. Reuse the project's plotting library, palette mapping and export command. For an unfamiliar option, consult the installed library's help or its official API reference.

1. Choose labels and units before styling. Use a short title. Add a reading cue when the sign, direction or baseline is easy to misread.
2. Use Roboto Condensed with a bold main title, smaller bold panel headings, regular axis labels and quieter ticks. Align related panels and reserve enough space for units and annotations.
3. Keep each entity's color consistent across comparisons. If panels encode a different variable, choose and label that mapping separately. Add shapes, line styles or patterns so readers can distinguish series without color. Prefer a single legend row beneath the plot when space permits. Remove redundant footers.
4. Export using the project's usual command and dimensions. Open the actual PDF, SVG or PNG at its intended reading size. Inspect cropped labels, overlapping marks, thin lines, ambiguous legends and misplaced annotations. If a font substitution or clipping changes the result, correct the script and export again.

For example, two policies compared across four panels should retain their colors and line styles in all four. Compare the exported panels side by side before delivering.
